## p01-simple-split（保留）

目的だったZMK・左右分割・Choc v1・親指キー・ソケットはんだ・JLCPCB発注（PCB＋部分PCBA）の学習は**すべて達成済み**。

残作業はXIAO 2個のdirect mountはんだ付けのみ（追加出費ゼロ・1〜2時間）だが、完成させない:

- p03では自作PCBにMCUを載せるため、既製ボードを他人のPCBに直付けする経験の転用価値が薄い
- Corne系42キーは日常運用に投入できず、「1週間試す」ができない
- Choc v1 Red・MBKキーキャップはChoc V2（MXステム）と非互換で部品も引き継げない

**残る資産**: XIAO nRF52840 が3個とも未使用のまま / `tools/keytest.html` / Chocソケットの余り / PCBはXIAOフットプリントの実例として参照可。

## p02-auto-kdk（保留）

**到達点はPCBの疎通確認まで。** 左右PCBのChocソケットはんだ付け（64箇所）を終え、ピンセットでソケットを短絡する方式で全数の導通・入力を確認した（右手34/35キー・`k` のみ断線、左手29/29キー）。ファーム書き込み・左右のBLE接続・central経由のHID出力も確認済み。

**ただしスイッチ・キーキャップ・ケースは未装着、バッテリーも未接続（USB給電）で、打鍵できる状態ではない。** 残作業に対して得られる設計入力が見合わないため完成させない。

- p03に必要な実測値（左右間隔・奥行きの揃え方・トラックパッド面との高さ差）は、**結局p03の実物を3Dプリントして手を乗せないと決まらない**
- バッテリー極性の再工作は一度失敗済み、トラックボールはモジュール再購入（¥4,500）が必要、本番スイッチ64個は¥5,000

**ただし2つの役割が残る:**

1. **ケース実物は、p03の配置検討モックアップ**として使える（左右間隔・高さ・角度を実寸で再現できる唯一の現物）
2. **スタビなし幅広キーの検証台**。これはp02でしか分からず、かつp03のレイアウト確定に必須（下記）

## p03: 中央トラックパッド統合・フルスクラッチ（次に着手）

目的: Magic Trackpadを左右分割キーボードの中央に統合し、**自作PCB＋自作ケース**で「机の上が1つにまとまる」構成を実現する。

ディレクトリ名は着手時に決める。

### 決まっていること（2026-08-03時点）

| 項目 | 決定 |
|---|---|
| ポインティング | **Apple Magic Trackpad（現行・感圧式）を左右の中央にはめ込む**。BLEでMacに直結する独立デバイスのため、ZMK側は一切関与しない |
| MCU | **Raytac MDBT50Q-1MV2 直付け**（¥1,185〜1,265／技適済み／約2mmで最薄） |
| 電源 | **エネループ単4×2（2.4V）を直結**。レギュレータ・充電IC不要 |
| キーレイアウト | **p02の `split-us60pct` をほぼそのまま**（Choc V2 19mmピッチ・64キー・左29/右35） |
| スイッチ | Kailh Deep Sea Silent MINI **Islet**（43gf 静音リニア）。~~Pink Island（35gf）~~ からキーキャップ込みの打ち比べで変更（2026-08-04） |
| キーキャップ | **YUZU（PFFプロファイル）をp02から流用**。再発注不要 |
| ケース | **自作・3Dプリント内製**（Bambu Lab X2D） |
| 複数Mac切り替え | **blueutil + ホットキー + ZMKマクロ**のソフトウェア方式 |
| ファームウェア | ZMK。ボード定義は `akdk_bt1` の生成物をテンプレートに自作 |

### 設計順序の原則：反復の安いものから固める

**ケース（3Dプリントで何度でも刷り直せる）を先に固め、PCB（1回$100〜200＋納期2〜3週間）を後に回す。**

ケースとPCBは相互依存する（PCBの外形・ネジ穴・コネクタ位置がケースを決め、ケースの厚みと配置がPCBを縛る）が、失敗コストが2桁違うので、先に安いほうで探索して寸法を確定させる。

### 作業順序

#### フェーズ0: 購入

- [ ] Bambu Lab X2D 単体 ¥126,000（AMSは使わないためComboは不要）
- [ ] Apple Magic Trackpad（現行・感圧式）≒¥19,800 — **初代の物理ヒンジ式は不可**

#### フェーズ1: 到着後すぐ潰せる検証（ケース設計に入る前）

- [ ] **複数Mac切り替えの実機検証**。最初に確認するのは「**Magic Trackpadが複数Macのペアリングを保持するか**」— ここが崩れると切り替え方針ごと崩れる
  - [ ] `blueutil --paired` でアドレス取得 → `--connect` / `--disconnect` の動作確認
  - [ ] Mac 3台へのスクリプト配置とホットキー登録
  - [ ] Bluetooth TCC権限の挙動確認
  - [ ] 「近接Macに奪われる」挙動への対処（非アクティブ時は掴まない／掴んだら離す）
- [ ] **Magic Trackpadの実測**（外形・厚み・角R・背面のポートとスイッチ位置）と断面スケッチ
- [ ] **公差テストピースの印刷**（トラックパッドの角Rと厚みの小片・爪のスナップ1箇所・ネジボス1個）。CAD習熟と機械の癖（実寸のXYズレ）の把握を同時に進める
- [x] **スタビなし幅広キーの検証**（キーキャップ到着後・p02実機＋サンプル軸の余りで実施）→ **合格・レイアウト確定（2026-08-04）**

#### フェーズ2: ケース設計（3Dプリントで反復）

一体化の度合いは安いイテレーションから上げる（`docs/decisions.md`「ケースの一体化は段階的に上げる」参照）。

- [ ] **単独トレイ**（トラックパッドの台のみ）を刷って、左右間隔・角度・高さを実物で追い込む
  - p02のケース実物を左右に置いて配置を再現する
  - トラックパッド面はキートップとツライチ〜2、3mm低めが定番。シム／調整脚で±3mm動かせるようにして実物で追い込む
- [ ] 気に入った配置を実測 → 左右間隔・角度・高さのパラメータ確定
- [ ] **耳付き中央ユニット** → **フルベース板**（500mm超は3分割印刷＋結合）→ **完全一体型**へ段階的に上げる
- [ ] 電池ボックスの機構設計（単4×2。既製ホルダーか、電池直抱え＋金属接点の自作か）
- [ ] トラックパッドの充電ポート・電源スイッチの逃げ、取り出し用の指掛かり穴

#### フェーズ3: PCB設計（ケースの寸法確定後）

- [ ] 回路設計: MDBT50Q + 乾電池直結 + USB-C + ESD保護 + リセット/電源スイッチ + 電池電圧分圧
- [ ] アートワーク: **アンテナのキープアウト厳守**。MCUは外周側・前寄り、電池は後端に配置して干渉源から離す
  - リファレンス設計を参照: `siderakb/mdbt-micro` / ErgoSNM / Skean
- [ ] **Raytacへレイアウトレビューを依頼**（PDFを `service@raytac.com` へ・無料・発注前必須）
- [ ] JLCPCBへ発注（PCB + 部分PCBA。ダイオード実装は工場に任せる）

#### フェーズ4: ファームウェア・組み立て

- [ ] ZMKボード定義の作成（`boards/p02-auto-kdk/generated/boards/arm/akdk_bt1/` をテンプレートに）
- [ ] **乾電池の放電カーブに合わせたZMK電池残量レポートの校正**（Li-Poとカーブが違うため、そのままでは残量表示が正しくない）
- [ ] キーマップ・コンボの移植（p02の資産を流用。トラックパッド採用でジェスチャ代替コンボは不要）
- [ ] 本番スイッチ Islet 64個＋予備を発注 ← ~~レイアウト確定後~~ **レイアウト確定済み（2026-08-04）、発注可能**
- [ ] Chocソケットのはんだ付け → 組み立て → 実機確認

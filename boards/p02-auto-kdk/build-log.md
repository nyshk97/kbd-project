組み立て、失敗、変更、気づきを時系列で記録する。

## ログ

- 2026-08-02: 左右PCBのChocソケットはんだ付け完了。ダイオード64個はJLCPCBのPCBAで工場実装済みのため、自分ではんだ付けするのはソケットのみ。
- 2026-08-02: 動作確認用の暫定キーマップを作成。Auto-KDK生成の `config/keymap.keymap` は**全キー `&none`** で、そのまま書き込むと押しても何も入力されない。US 60%相当の layer_0 と、Fn/Bluetooth の layer_1（`&mo 1` で `F1`〜`F12`・`BT_SEL 0-4`・`BT_CLR`）を記述して zmk-config リポジトリの main に push（`672d54d`）。GitHub Actions run `30730307052` 成功、artifactを `firmware-built/firmware/` に配置。
- 2026-08-02: **コントローラボードは左右鏡像の別部品**と判明。当初「2枚は同一品でファームが役割を決める」と誤認したが、BOOTH商品説明に「形状が対称な2種類のコントローラがセットになっています」と明記されていた。裏面シルクは `AKDK-BT1-1` / `AKDK-BT1-2`。生成PCBデータのフットプリント名は**左手 = `MS88SF2_1-1-3-SIDE2`、右手 = `MS88SF2_1-1-3-SIDE1`**（`pcb/split-us60pct-{left,right}-pcb.json` の LIB 要素）。外形（レール込み）の張り出し方向もコンスルーパッド列を基準に左右反転している。
- 2026-08-02: **コントローラはPCBのソケット実装面（bottom側）に載せる**。スイッチを挿す面ではない。公式の `img/wireless-controller-set.png` でも、紫のChocソケットと黒いダイオードが見える面にコントローラが載っている。構造的にも、トップケースがスイッチプレートを兼ねて上から被さり、コントローラとバッテリーはPCB下の空間に収まる。
- 2026-08-02: コンスルーを加工（無線版付属は11ピン→不要2本を抜いて樹脂をカット）、コントローラのレールをペンチで折り取り、装着。**ボード側のコンスルー穴はマトリクス4列×9行**で、19/18/17/16mmのキーピッチに対応。19mmピッチなので**一番外側（基板の縁に近い）の列**を使う。マウスバイト（ミシン目）の跡が穴と紛らわしいが、コンスルー穴は白いシルク枠の内側にある完全な円、マウスバイト跡は枠の外の半円で別物。
- 2026-08-02: ファームウェア書き込み。**電源スイッチOFFでUSB接続 → `NRF52BOOT` としてマウント**。`cp` は「could not copy extended attributes: Device not configured」で exit 1 を返すが、**ドライブがアンマウントされていれば成功**（READMEにも明記の挙動）。`INFO_UF2.TXT` の Board-ID は左右とも `auto-kdk-nrf52840-1` で、**左右の判別には使えない**。
- 2026-08-02: ZMK起動を確認。USB上の表示は **右(Central) = `split_us60pct` / `ZMK Project`**、**左(Peripheral) = `Generic CDC`**。左が別名なのは `ZMK_KEYBOARD_NAME` が `Kconfig.defconfig` で右手shieldにしか定義されていないため。Peripheral側はHIDを出さずCDCのみ。
- 2026-08-02: 右手35キーのピンセット全数チェック（ソケットの対角2端子を短絡）。**34キーOK、`k` のみ反応せず**。`k` は row2(`akdk_d 17`) × col3(`akdk_d 12`)。同じ行（h・j・l・;・'・Enter）も同じ列（9・i・,）も反応するため、断線はその交点に限定される。追いはんだでは直らず、ダイオードの向きも隣接キーと同じに見えるため原因未特定。**プロトタイプとして1キー欠けたまま先に進む判断**（ケースを閉じる前に再診断する）。
- 2026-08-02: 左手29キー全数OK。左手の入力が右手経由でMacに届くことを確認し、**左右のBLE接続も成立**（初回ペアリングは自動）。
- 2026-08-02: トラックボールのセンサーモジュールのFFCコネクタのラッチを破損（爪で起こそうとして外れた）。**p02ではトラックボールを見送る判断**。完成版ではトラックパッドを検討する方向のため、再購入(¥4,500)せず先に進む。ケースのトラックボール穴は開いたままになる。
- 2026-08-02: **バッテリー DTP502535(PHR) の極性がAuto-KDKコントローラと逆**と判明。ボード側は導通チェック（USB-Cシェル＝GNDとPHコネクタ端子の導通）でシルク通りと確認済み。コネクタのツメで決まる挿し方向では赤線が `−` 側に来るため、そのまま挿すとボードが即死する。コンタクトの差し替えかはんだ付けでの入れ替えが必要。左右でコネクタが鏡像配置なので、右手側は要再確認。

- 2026-08-02: 軸の打ち比べ実施。サンプル3種（Islet 43gf / Pink Island 35gf / Whale 45gfタクタイル）を実機PCBのソケットに挿して比較し、**Kailh Deep Sea Silent MINI Pink Island（35gf 静音リニア）に決定**。当初の本命だったIslet（43gf）を実打鍵で覆した。
- 2026-08-02: バッテリーの極性入れ替えのため線を切ったが、被覆剥きで難航して中断。**剥き出しの芯線は絶縁テープで養生した状態で保留**。p02はUSB給電（右手をMacへ、左手を給電のみ）でも動作するため、バッテリーは完成をブロックしない。
- 2026-08-02: 完成版は**フルスクラッチで設計する方針に決定**。ポインティングデバイスは**Apple Magic Trackpad（現行・感圧式）を左右分割の中央にはめ込む**構成。詳細と論点は `docs/decisions.md` を参照。

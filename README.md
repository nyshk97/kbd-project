# kbd-project

自分用の最高のキーボードを作るための、自作分割キーボードプロジェクト。
量産・販売は目的にしない。

## 概要

- 個人利用を最優先し、一般化・量産性・販売価格の最適化は優先しない
- 最終形は**左右分割・ロースタッガード・完全無線**に、**Apple Magic Trackpadを中央に統合**した一体型ケースを目指す
- 電源は**乾電池（エネループ単4×2）**。充電の管理から解放されることを要件にする
- 最初から最終形を作らず、簡単な試作を複数台作って段階的にリスクを潰す
- ファームウェアは**ZMK**、MCUは**Raytac MDBT50Q-1MV2 直付け**、スイッチは**Kailh Choc V2（19mmピッチ）**

方針の変遷と、そう決めた理由は `docs/decisions.md` に記録している。

## ディレクトリ構成

使うものだけを置く最小構成にする。

- `docs/` : プロジェクト全体の方針・ロードマップ・意思決定
  - `decisions.md` : 設計判断とその理由（**このプロジェクトの中心的なドキュメント**）
  - `roadmap.md` : 試作ごとの目的と作業順序
  - `parts.md` / `target.md` : 部品メモ、旧方針の最終形メモ
- `boards/p01-simple-split/` : 初号機（保留）。目的・部品表・作業ログ・ZMK設定
- `boards/p02-auto-kdk/` : 2号機（保留）。Auto-KDK生成データ一式・発注記録・作業ログ
- `target/` : 最終的に目指す統合版。旧方針のKLE/Ergogen成果物はレイアウト検討の参考資料として残す

p03のディレクトリは着手する時点で追加する。まだ使わないディレクトリは作らない。必要になった時点で、各試作機の配下に次を追加する。

- `layout/` : KLEや物理配列メモ
- `pcb/` : KiCadファイル、GerberなどのPCB成果物
- `case/` : ケース3Dデータ、印刷用データ
- `firmware/` : ZMK設定ファイル
- `keycaps/` : キーキャップ3Dデータ

試作をまたいで再利用するものが出てきたら `shared/` を作る。外部資料や生成スクリプトが必要になったら `vendor/` や `tools/` を作る。
